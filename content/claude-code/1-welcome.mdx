Seven days, one lesson and one build task a day. By day 7 you'll have a full-stack app deployed at a public URL, built with Claude Code, whose repo has a working `CLAUDE.md`, one custom subagent, one hook and one MCP server in use.

## How each day works

1. Read or watch the lesson (20–30 min).
2. Do the build task (60–90 min).
3. Check it against **Done when** and mark the lesson complete.
4. Post what you shipped in #daily-ships on Slack.

## The demo

On day 7 you show a live URL and walk through how Claude Code built it, in 3 minutes. Pick something small enough to finish. You can always add to it after.
